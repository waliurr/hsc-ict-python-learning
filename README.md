# HSC ICT Python Learning

Welcome to HSC ICT Python Learning!

This repository provides beginner-friendly Python programming
examples, Bangla explanations, and practice problems for HSC ICT
students in Bangladesh.

## Learning Materials

1. Python Introduction
2. Variables and Data Types
3. Input and Output
4. Operators
5. Conditional Statements
6. Loops
7. Practice Problems

## How to Use

- Read the lesson explanations.
- Explore the Python code examples.
- Run the programs on your computer.
- Solve the practice problems.
- Compare your solutions with the examples.

## Requirements

- Python 3
- A code editor or Python IDLE

## Language

Explanations: Bangla  
Programming language: Python

## Purpose

This repository is an educational resource for HSC ICT students.

Happy Learning!
